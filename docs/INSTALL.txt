RenZhi · 认知统计
macOS 14+ · Apple Silicon / Intel

1. 将“认知统计.app”拖到 Applications 文件夹，双击打开。
2. 登录本机飞书，点击小窗的“连接飞书”。
3. 首次没有会话时，点“打开考勤”，在飞书中完成学院的一卡通登录。

连接成功后可以关闭考勤页面。每约 5 分钟直接查询接口；零点及电脑唤醒后刷新。
图钉切换置顶，拖动空白处移动窗口，…菜单可同步、开启提醒、断开或退出。
“今日认知提升”显示有效时长；“本月认知提升”仅显示正常出勤天数。

不需要屏幕录制或辅助功能权限。通知权限可选。
没有内置账号、个人考勤、密码或 token。运行时在本机读取现有的一卡通网页会话。
会话过期、飞书升级或缓存变化后，可能需要重新点“打开考勤”。
本版适配上海创智学院的一卡通服务，不是适用于所有组织的通用飞书考勤工具。

这是采用 ad-hoc 签名、未经 Apple Developer ID 公证的开源应用。
若首次打开被系统拦截，请核对下载来源后，到“系统设置 → 隐私与安全性”允许打开。
无需关闭 Gatekeeper 或授予完全磁盘访问权限。
