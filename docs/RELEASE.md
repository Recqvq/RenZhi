认知统计：原生、轻量的 macOS 悬浮窗。

- 今日认知提升：显示服务端有效时长。
- 本月认知提升：仅统计正常出勤天数。
- 可拖动、可选置顶，约每 5 分钟更新，支持零点和电脑唤醒后刷新。
- 无截图、OCR、菜单栏图标或运行时第三方依赖。

**下载**：推荐 DMG，打开后拖入 Applications；ZIP 可直接解压。两个包都包含 Apple Silicon / Intel 通用架构，需要 macOS 14+。SHA256SUMS 用于校验。

**适用范围**：上海创智学院一卡通 + 飞书桌面版，需使用者自己的有效账号。首次点“连接飞书”，没有会话时再点“打开考勤”。登录过期或飞书存储变化时可能需要重新连接。

**签名**：此版本采用 ad-hoc 签名，尚未经过 Apple Developer ID 公证。首次启动可能需要在系统设置的“隐私与安全性”允许打开，无需关闭 Gatekeeper。

安装包由 GitHub Actions 从标签对应源码生成，不附带维护者的登录状态、个人数据或本机配置。所有源码及图标生成器以 MIT 许可开放，详见仓库 README、PRIVACY.md 和 CONTRIBUTING.md。
